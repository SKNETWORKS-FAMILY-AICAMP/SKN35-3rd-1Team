# images

개발과 시연에 쓸 작품 이미지와 출처 정보를 둡니다.

## 들어갈 파일

- 이미지 파일: 작품 slug를 파일 이름으로 씁니다 (예: `the-starry-night.jpg`)
- `credits.json`: 파일별 원본 페이지 주소, 소장처, 이용 조건

## 규칙

- DB에는 이미지 파일이 아니라 주소(`artworks.image_url`)를 저장합니다. 원본 페이지와 이용 조건은 `image_source_url`, `image_license`에 넣습니다.
- 외부 사이트의 이미지 주소를 그대로 쓰면 링크가 끊기거나 차단될 수 있습니다. 발표에 쓸 작품은 사본을 확보해 직접 제공하는 편이 안전합니다.
- 원본 해상도 파일은 저장소에 올리지 않습니다. 화면에 필요한 크기로 줄여서 둡니다.
- 실제 배포에서는 저장소 용량과 트래픽을 고려해 오브젝트 스토리지 사용을 검토합니다.
