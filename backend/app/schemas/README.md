# schemas

API 요청과 응답의 형식을 Pydantic 모델로 정의합니다. 프론트엔드의 `src/types/`와 필드 이름을 맞춥니다.

## 들어갈 파일

- `auth.py`: 가입·로그인 요청, 토큰 응답
- `catalog.py`: 사조, 작가 카드와 상세, 작품 카드와 상세
- `chat.py`: 질문 요청, 답변 응답, 출처 항목
- `activity.py`: 좋아요·팔로우 상태 응답
- `library.py`: 캘린더 날짜 항목, 하루 상세
- `recommendation.py`: 추천 작품 항목, 추천 작가 항목

## 미리 정해 둘 응답 형식

**챗봇 응답**에는 다음이 들어갑니다.

- `answer`: 답변 본문
- `refused`: 근거 문서가 없어 답변을 거절했는지 여부
- `sources`: 근거 목록. 항목마다 `document_id`, `title`, `doc_type`, `source_name`, `source_url`

**챗봇 요청**에는 `question`과 `history`(이전 대화 몇 턴)가 들어갑니다. 대화 이력은 서버에 저장하지 않고 프론트가 보냅니다.

**추천 응답** 항목에는 작품 카드 정보와 함께 `reason`(예: 어떤 좋아요 작품과 비슷해서 추천됐는지)을 둘 수 있습니다.

## 규칙

- DB 모델을 그대로 반환하지 않습니다. `password_hash`나 `embedding`이 실수로 노출되는 것을 막습니다.
- 목록용(카드)과 상세용 스키마를 나눕니다. 목록 응답에 긴 설명을 싣지 않습니다.
- 작품 카드에는 로그인 사용자의 좋아요 여부(`is_liked`)를 포함할지 팀에서 정합니다. 포함하면 프론트의 추가 호출이 줄어듭니다.
