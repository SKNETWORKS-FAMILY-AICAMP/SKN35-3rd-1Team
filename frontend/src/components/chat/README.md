# chat components

작품 도슨트 챗봇 화면을 구성하는 컴포넌트를 둡니다.

## 들어갈 파일

- `ChatPanel.tsx`: 채팅 영역 전체
- `MessageList.tsx`, `MessageBubble.tsx`: 대화 표시
- `ChatInput.tsx`: 질문 입력
- `SourceList.tsx`: 답변의 근거 문서와 출처 링크

## 규칙

- 답변마다 `SourceList`를 함께 보여 줍니다. 출처 표시가 이 서비스의 차별점입니다.
- 응답의 `refused`가 참이면 일반 답변과 구분되는 모습으로 표시합니다.
- 대화 이력은 서버에 저장되지 않습니다. 작품 상세 화면의 상태로 들고 있다가 질문할 때 최근 몇 턴을 함께 보냅니다.
- 다른 작품으로 이동하면 대화를 비웁니다. 챗봇은 선택한 작품의 문서만 근거로 답하기 때문입니다.
- 답변을 기다리는 동안 입력을 막고 진행 중임을 표시합니다.
