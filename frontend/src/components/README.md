# components

여러 화면에서 재사용하는 UI 조각을 기능별 폴더로 나눕니다.

| 폴더 | 내용 |
| --- | --- |
| `artwork/` | 작품 카드, 작품 정보, 좋아요 버튼 |
| `artist/` | 작가 카드, 작가 소개, 팔로우 버튼 |
| `chat/` | 도슨트 채팅창, 메시지, 입력창, 출처 목록 |
| `recommendation/` | 비슷한 작품, 맞춤 작품, 추천 작가 |
| `library/` | 내 서재 캘린더, 하루 상세 |
| `common/` | 버튼, 로딩, 오류, 헤더, 모달 |

## 규칙

- 컴포넌트는 props로 받은 것을 그립니다. 데이터 조회가 필요하면 `hooks/`의 훅을 씁니다.
- 한 화면에서만 쓰는 조각은 `pages/` 옆에 두어도 됩니다. 두 곳 이상에서 쓰게 되면 여기로 옮깁니다.
- 로딩, 빈 결과, 오류 세 가지 상태의 모습을 컴포넌트마다 정해 둡니다.
