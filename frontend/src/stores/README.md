# stores

여러 화면이 함께 쓰는 전역 상태를 둡니다.

## 들어갈 파일

- `authStore.ts`: 로그인 사용자 정보와 토큰, 로그인·로그아웃 동작

## 여기 두지 않는 것

| 상태 | 두는 곳 | 이유 |
| --- | --- | --- |
| 작품 목록, 추천 결과, 좋아요 목록 | 서버 데이터 캐시 (`hooks/`) | 서버가 원본입니다. 전역 상태에 복사하면 두 값이 어긋납니다. |
| 채팅 대화 이력 | 작품 상세 화면의 상태 | 작품을 벗어나면 필요 없습니다. |
| 선택한 탭, 열린 모달 | 해당 컴포넌트의 상태 | 다른 화면이 알 필요가 없습니다. |

## 규칙

- 토큰을 어디에 보관할지(메모리, 저장소) 팀에서 정하고 `authStore` 한 곳에서만 다룹니다.
