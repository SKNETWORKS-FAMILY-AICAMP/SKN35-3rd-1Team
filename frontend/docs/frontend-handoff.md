## 채팅 연결과 성능

`DocentConversation`이 작품·계정별 메시지와 진행 상태를 관리하고 `ArtlogApi.chatStream`이 POST SSE를 읽습니다. `token`은 이어 붙이고 `replace`는 임시 텍스트 교정에 사용하며 `done`에서 검증된 답변·출처·제안으로 확정합니다.

질문 1~500자, history 최대 12개·각 4000자로 제한합니다. 답변 생성 중 재전송을 막고 글자별 대기 효과를 제거했습니다. 응답 헤더 및 스트림 무응답에 45초 제한을 적용합니다. 전체 요청이 무조건 45초 안에 끝난다는 뜻은 아닙니다.

SSE 미지원(404·405·501)에만 JSON으로 전환합니다. 중간 오류·타임아웃·503을 자동 재전송하면 AI 호출·DB 저장이 중복될 수 있어 수동 재시도로 처리합니다. 실제 모드의 프론트는 질문 의미를 분석해 먼저 차단하지 않습니다. 거절 분류·검색·생성은 서버 책임입니다.

작품 상세·작가·추천 등은 상태의 요청 캐시를 재사용합니다. 계정 변경 시 개인 캐시를 초기화하고 이전 응답을 버립니다. 이는 서버에 도착한 요청의 실행을 취소하는 기능은 아닙니다.

## 인증·공개 범위

Firebase SDK의 ID 토큰을 Bearer로 전달하고 401이면 같은 세션에서 한 번 강제 갱신합니다. 계정 변경 후에는 이전 요청을 새 계정 토큰으로 재전송하지 않습니다. 서버는 Firebase 검증 UID로 사용자를 결정하고 개인 리소스 소유권을 검사해야 합니다.

실제 감상·컬렉션은 서버 저장입니다. 새 감상 기본값은 비공개이며 `entry_id`로 수정·삭제합니다. 공개 피드에서는 본인 작성자 ID와 로그인 공개 ID가 일치할 때만 삭제 조작을 제공하고 서버가 최종 권한을 검사합니다. 다른 사람 프로필에는 공개 감상만 표시됩니다.

미리보기는 브라우저 저장이고 실제 AI나 공개 게시가 아닙니다. 이전 로컬 메모를 자동으로 서버에 업로드하지 않습니다. Firebase/Google에서 생년월일·성별을 자동 조회하지 않습니다.
