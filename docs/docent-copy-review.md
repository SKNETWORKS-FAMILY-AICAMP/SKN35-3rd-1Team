# 도슨트 고정 문구 확인

2026-10-14 기준. 모든 문구는 개별 확인 후 런타임에 적용했다. 중괄호 안 값은 실제 작가·작품 이름 또는 추천 이유로 바꾼다.

| 번호 | 상황 | 제안 문구 또는 형식 | 상태 |
| --- | --- | --- | --- |
| 1 | 작품 범위 밖 질문 | 해당 작품과 작가에 대해서만 대화 할 수 있어요. | 확정 |
| 2 | 검수 중인 작가 | 현재 {작가명} 작가의 자료는 검토 중에 있어요. | 확정 |
| 3 | 미수집 작가 | {작가명}에 관한 자료는 준비 중 입니다. | 확정 |
| 4 | 현재 다루지 않는 작가 | 현재 {작가명}의 자료는 검토 중에 있어요. | 확정. 아래 상태 한계 참고 |
| 5 | 소장 작품의 다른 작가 | {작가명}의 작품을 선택하면 해당 작가에 관해 대화할 수 있어요. | 확정 |
| 6 | 승인 근거 없음·모델 유보 | 현재 검수된 자료로는 정확한 확인이 어려워요. 다른 궁금하신 내용이 있으신가요? | 확정 |
| 7 | 자료 검색 실패 | 작품 자료를 불러오지 못했어요. 잠시 후 다시 시도해 주세요. | 확정 |
| 8 | 현재 작품의 유사 추천 | 이 작품과 비슷한 결을 가진 작품을 더 둘러보세요. 『{작품명}』 | 확정 |
| 9 | 회원 추천 | 이런 작품은 어떠신가요? 『{작품명}』 — {추천 이유} | 확정. 이유 없으면 작품명만 표시 |
| 10 | 유사 추천 결과 없음 | 현재 이 작품과 유사한 작품 정보가 아직 준비되지 않았어요. | 확정 |
| 11 | 회원 추천 결과 없음 | 아직 충분한 취향 데이터가 쌓이지 않았어요. | 확정. 아래 상태 한계 참고 |
| 12 | 비로그인 취향 추천 | 로그인 후 감상 기록이 쌓이면 더 정교한 추천을 받아볼 수 있어요. 현재 작품과 비슷한 작품을 먼저 만나보세요. | 확정. 유사 작품 제목을 이어 표시 |

AI 연결·생성 오류와 스트리밍 오류 문구는 현재 서버 안내를 사용한다. 평가 후 수정이 필요하면 별도로 문구를 확인한다.

4번 분류는 작가 이름이 현재 수집 목록에 없다는 사실만 확인하며 실제 검토 진행 상태는 확인하지 못한다. 11번은 추천 결과가 비어 있다는 사실만 확인하며 감상 기록 부족이 원인인지 판별하지 않는다. 따라서 이 두 문구는 실제 상태와 다르게 들릴 수 있다.
