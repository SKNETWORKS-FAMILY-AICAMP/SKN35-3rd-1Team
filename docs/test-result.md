# RAG·LLM 및 마이페이지 운영 테스트 결과

## 결론

2026-10-14 배포 주소를 직접 검사한 결과, **운영 서버에는 현재 저장소의 RAG·LLM 및 확장 마이페이지 코드가 반영되어 있지 않다.** 백엔드 상태 확인과 작품 목록은 정상이나 채팅 30문항은 전부 `501 Not Implemented`, 확장 마이페이지 API 17개 검사는 전부 `404 Not Found`였다. 따라서 이번 회차의 **30문항 운영 성공률은 0/30(0%)**이며, 이는 답변 품질 실패가 아니라 채팅 기능의 운영 미배포로 인한 실행 실패다.

정확성, 검색 근거, 거절, 출처 정합성, 멀티턴, 환각, 말투·설명 순서는 답변 자체가 생성되지 않아 평가에서 제외했다. 제외 항목과 이유는 아래에 명시했다.

### 출처 URL·라이선스 사전 검사

이 검사는 챗봇이 실제로 반환한 출처가 아니라, 23개 정상 답변 문항의 **기대 근거 문서 메타데이터**를 검사한 것이다.

- 기대 문서 존재: 23/23
- 출처 URL 필드 존재: 23/23
- 라이선스 필드 존재: 23/23
- 자동 HTTP 2xx/3xx: 19/23
- 자동 요청을 막은 4개 중 NGA, Met, MoMA 3개는 브라우저 방식으로 열림 확인
- 벨베데레 《키스》 URL 1개는 자동 요청 403 및 브라우저 검사 도구 오류로 수동 확인 필요
- 두 방식 합산 링크 확인: 22/23(95.7%)

따라서 URL 형식과 라이선스 저장 상태는 확인했지만, 실제 챗봇이 이 문서를 검색하고 같은 출처를 반환했는지는 아직 확인하지 못했다.

## 마이페이지 운영 검증

임시 Firebase 이메일 계정 2개를 만들어 운영 API를 직접 호출했다. 검사 종료 후 두 Firebase 계정은 삭제했다. 현재 운영 OpenAPI에는 아래 확장 경로가 없고, 모든 호출이 `404`여서 기능 판정은 모두 실패 또는 평가 불가다.

| 검증 항목 | 기대 | 운영 결과 | 판정 |
| --- | --- | --- | --- |
| 인증 없이 설정 접근 | 401 | 404 | 실패: 경로 미배포 |
| 설정 서버 저장 후 재조회 | 저장값 유지 | 404 | 평가 불가 |
| 설정 enum·중복 우선순위 검증 | 422 | 404 | 평가 불가 |
| 두 계정 설정 분리 | A 설정이 B에 보이지 않음 | 404 | 평가 불가 |
| 비공개 감상평 계정 분리 | B 조회 null, 공개 피드 미노출 | 404 | 평가 불가 |

운영 프론트는 HTTP 200으로 열리지만 배포된 `main.dart.js`에도 `/api/me/profile`, `/api/me/collections`, `/api/me/taste`, `/api/me/collections/chat` 문자열이 없다. 즉 백엔드뿐 아니라 프론트도 확장 마이페이지 이전 버전이다.

## 로컬 구현과 운영 배포 구분

운영 장애가 현재 저장소 코드 자체의 단위·API 테스트 실패인지 확인하기 위해 관련 테스트를 실행했다.

- 질문 파일 구조·분류 검사 포함 관련 백엔드 테스트: **207/207 통과**
- 범위: 인증, 채팅 저장, 다이어리, 마이페이지, 컬렉션, 도슨트 설정, 검색기, 질문 분류, 평가 fixture

따라서 이번 실패의 1차 분류는 **검색 문제나 LLM 답변 문제가 아니라 배포·통합 문제**다. 로컬 테스트 통과가 실제 TiDB·Chroma·OpenAI 연결과 생성 답변 품질을 보장하지는 않는다.

## 재검증 완료 기준

1. 운영 OpenAPI에 `/api/me/profile`, 다이어리, 컬렉션, 취향, 컬렉션 채팅 경로가 보인다.
2. 채팅 API가 정상 질문에는 200, 범위 밖·근거 부족 질문에는 구조화된 `refused: true`를 반환한다.
3. version 2 검색 단독 평가에서 클림트·실레를 포함한 기대 `doc_key` 적중률을 기록한다.
4. 30문항 전부에 대해 답변, 검색 문서, 출처, URL, 라이선스, 거절, 환각, 멀티턴을 다시 판정한다.
5. easy/professional 두 설정과 설명 우선순위 2종 이상을 같은 질문으로 비교한다.
6. 임시 계정 2개로 설정·비공개 감상·컬렉션 데이터 분리를 재검증한다.
