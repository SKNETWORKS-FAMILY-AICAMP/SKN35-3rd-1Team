## RAGAS 방식 생성 평가

설치 패키지의 버전 차이로 결과가 흔들리지 않도록, PLAN.md에 허용된 **동일 기준의 구조화 LLM Judge**를 사용했다. 평가 모델과 프롬프트를 고정하고 다음 정의로 0~1 점수를 계산했다.

- Faithfulness: 답변의 사실 주장이 검색 Context로 직접 뒷받침되는 비율
- Answer Relevancy: 질문 의도에 직접 답하고 불필요한 내용이 적은 정도
- Answer Correctness: 검색 Context와 문항별 기대 조건에 비춰 핵심 사실·불확실성 처리가 정확한 정도

거절 기대 8문항은 위 세 생성 지표 평균에서 제외하고 거절 정확도로 별도 평가했다. 정상 답변 37문항 중 `prompt-008`만 Answer Relevancy 0.80으로 목표에 미달했다. 동일한 `gpt-4.1-mini`가 답변과 평가에 사용되어 자기평가 편향 가능성이 있으므로, 최종 실패 판정은 `refused`, 실제 출처 문서, 기대 조건을 함께 대조했다.

## 말투별 차이

같은 질문을 `easy`, `standard`, `deep`으로 각각 실행했다.

> 야경은 왜 평범한 단체 초상화와 다르게 느껴져?

- easy: 쉬운 문장과 짧은 용어 풀이 중심, 적합도 0.90
- standard: 구도·빛·인물 배치를 균형 있게 설명, 적합도 0.90
- deep: 테네브리즘, 상징, 시대 맥락을 더 세밀하게 연결, 적합도 0.95
- 종합 판정: 세 답변의 복잡도·깊이·용어 사용이 **명확히 구분됨**

세 답변은 모두 같은 승인 근거 범위를 사용했고, 말투 변경 때문에 새로운 사실을 추가하는 문제는 확인되지 않았다.

## 청크 경계·overlap 평가

실제 인접 청크에 답이 나뉜 문항과 기존 프롬프트 문항을 포함해 18문항의 정답 청크를 지정했다. 각 설정에서 동일 질문 임베딩과 동일 문서 범위를 사용하고 raw cosine Top-5를 비교했다.

현재 0자가 세 설정 중 Recall@5가 가장 높았다. 50자와 100자는 다음 문제를 해결하지 못했다.

- `detail-007`: 세잔 《사과와 오렌지》 작품 청크 대신 영향·생애 문서가 상위에 위치
- `boundary-002`: 《야경》의 극적 단체 초상과 두 지휘관 청크가 Top-5 밖
- `boundary-003`: 렘브란트 초기 촛불과 성숙기 명암 비교 청크가 Top-5 밖
- `prompt-008`: overlap이 커질수록 필요한 묵서 번역 청크의 순위가 오히려 하락
- `boundary-001`: 모네 색채 경계 청크 두 개 중 하나만 Top-5에 포함

현재 운영 retriever에는 작품 문서 보장 자리, 비교 문서 보장 자리, pinned 보정문이 있으므로 실제 채팅은 raw cosine보다 좋은 근거를 받을 수 있다. 이 실험은 overlap 자체의 효과를 분리하기 위해 그 보장 규칙을 제외했다. 따라서 기존 문서 단위 검색 적중률 22/23과 청크 raw Top-5 결과를 같은 수치로 비교하면 안 된다.

권장 조치는 overlap 변경이 아니라 다음 순서다.

1. `detail-007`의 작품 ID·문서 범위·Chroma 메타데이터 연결 확인
2. 작품 해설과 비교 문서 보장 자리가 raw 순위 실패를 실제 Context에서 보완하는지 확인
3. 긴 생애 문서가 Top-5를 과점하지 않도록 문서별 최대 청크 수 또는 reranker 검토
4. 위 조정 후 동일 18문항으로 재측정

#### 1. `detail-007` — 세잔 작품 직접 근거 누락

- 질문: **천과 과일이 기울어져 보이는 구성이 화면에 어떤 효과를 줘?**
- 실제 답변:

> 천과 과일이 기울어져 보이는 구도는 화면에 안정적인 구조와 동시에 동적인 긴장감을 줍니다. 폴 세잔은 전통적인 단일 시점 원근법을 느슨하게 하면서 여러 면을 한 화면에 보여주는 방식을 사용했는데, 이로 인해 대상들이 평면적으로도 입체적으로도 보이게 하여 보는 이로 하여금 형태와 공간을 새롭게 인식하게 합니다. 기울어진 천과 과일은 형태의 단순화와 색면 처리로 부피감을 만들면서도, 화면 전체의 균형과 리듬을 이루어 세잔 특유의 질서 있는 구성미를 드러냅니다. 이러한 구도는 정물화임에도 불구하고 자연을 관찰하는 화가의 시각과 화가가 화면을 구조화하는 태도를 잘 보여줍니다.

- 실제 출처: `paul-cezanne/influence`
- 실패 이유: 답변 문장 자체는 자연스럽지만, 질문 대상인 《사과와 오렌지》의 직접 작품 문서가 아니라 세잔의 일반적인 영향 문서만 사용했다. 따라서 작품에 관한 구체적인 설명이 실제 승인 문서에 근거했는지 확인할 수 없다.
- 기대 동작: `paul-cezanne/apples-oranges`의 작품 해설 청크를 우선 검색하고, 그 근거 안에서만 기울어진 구도·균형·긴장 효과를 설명한다.

#### 2. `detail-008` — 《야경》 작품 직접 근거 누락

- 질문: **인물들을 줄 세우지 않고 움직이는 순간처럼 배치한 이유는 뭐야?**
- 실제 답변:

> 렘브란트가 『야경』에서 인물들을 줄 세우지 않고 움직이는 순간처럼 배치한 이유는, 그가 편지에서 언급한 "가장 위대하고 가장 자연스러운 움직임"을 표현하려는 의도와 관련이 있습니다. 즉, 단순히 정적인 초상화가 아니라, 실제 현장에서 벌어지는 역동적인 순간을 포착하고자 했던 것입니다. 작품 속 인물들은 각기 생생한 개별 초상으로 묘사되어 있으며, 전통적인 질서 있는 군중 배치 대신 무질서하면서도 연극적인 구도를 이루고 있습니다. 이러한 배치는 민병대의 임무 수행이라는 주제를 드러내면서도, 동시에 그들의 도덕적 탁월성과 침착함을 강조하는 효과를 냅니다. 구도 면에서 보면, 인물들은 자연스러운 동작과 표정으로 서로 어우러져 있어, 그림 전체에 생동감과 깊이를 더합니다. 색채와 붓질은 부분적으로 거칠고 변화무쌍하여, 빛과 그림자의 대비를 통해 인물들의 입체감과 공간감을 강조합니다. 이러한 요소들이 합쳐져 렘브란트가 의도한 "감정"과 "동기"가 자연스럽게 전달되는 작품이 되었습니다.

- 실제 출처: `rembrandt/bio.en`, `rembrandt/timeline-05`
- 실패 이유: 《야경》의 구도에 관한 질문인데 작품 직접 해설 없이 생애·연표 문서만 출처로 사용했다. 특히 편지, 도덕적 탁월성 등 구체적인 표현이 실제 검색 근거와 정확히 대응하는지 확인하기 어렵다.
- 기대 동작: 《야경》 작품 직접 문서를 우선 사용해 정적인 단체 초상 대신 행진 직전의 움직임과 극적인 장면을 표현했다는 범위로 설명한다.

#### 3. `compare-002` — 한쪽 근거만으로 비교 답변 생성

- 질문: **모네와 세잔은 자연을 표현하는 방식이 어떻게 달라?**
- 실제 답변:

> 클로드 모네와 폴 세잔은 자연을 표현하는 방식에서 차이가 있습니다. 모네는 자연을 고정된 형태가 아니라 빛과 대기에 따라 계속 변하는 시각적 경험으로 보았습니다. 그는 야외에서 직접 관찰하며 짧고 나뉜 붓질과 밝은 색을 사용해 순간적인 인상을 포착했고, 빛의 변화에 따른 색채와 분위기를 중시했습니다. 예를 들어, 『인상, 해돋이』에서는 흐릿한 안개와 빛의 반사, 그리고 태양의 색 대비를 통해 자연의 순간적 인상을 표현했습니다. 반면, 세잔은 자연을 보다 구조적이고 견고한 형태로 해석하여, 기하학적 형태와 색면을 통해 자연의 본질을 탐구하는 경향이 있습니다. 모네의 화법은 빛과 색의 변화에 집중하여 순간적인 느낌을 강조하는 반면, 세잔은 형태와 공간의 안정성을 추구하는 점에서 차이가 납니다. 이러한 차이는 두 화가가 자연을 바라보는 관점과 표현 방식에서 비롯된다고 할 수 있습니다.

- 실제 출처: `claude-monet/technique`, `claude-monet/impression-sunrise`, `claude-monet/bio`
- 실패 이유: 검색된 승인 근거는 모두 모네 자료인데, 세잔 설명까지 일반 지식으로 만들어 비교했다. 양쪽 근거가 필요한 비교 질문에서 한쪽 자료만으로 답한 것이 핵심 문제다.
- 기대 동작: 세잔 직접 근거를 추가 검색한다. 그래도 찾지 못하면 “모네에 대해서는 확인되지만 세잔 자료가 없어 정확한 비교는 어렵다”고 부분 답변하거나 거절한다.

#### 4. `evidence-002` — 기대값을 재검토해야 하는 문항

- 질문: **고흐가 침대를 그릴 때 정확히 무슨 생각을 했는지 한 문장으로 말해줘.**
- 실제 답변:

> 고흐는 침실을 그릴 때 색으로 휴식과 잠의 느낌을 주고자 했다고 편지에서 밝혔습니다. 작품에서는 단순한 가구와 강한 색채, 그리고 일부러 비뚤어진 원근법을 사용해 안정감과 편안함을 표현하려 했습니다. 특히 넓고 평평한 색면과 굵은 윤곽선은 일본 판화에서 받은 영향을 보여 주며, 침대와 의자 같은 소박한 생활 도구들이 방 안의 차분한 분위기를 만듭니다.

- 실제 출처: `vincent-van-gogh/commentary-the-bedroom`
- 기존 실패 판정 이유: 질문이 “정확히 무슨 생각”을 요구하므로 알 수 없는 내면을 단정하지 말고 거절해야 한다는 기대값을 적용했다.
- 재검토 결과: 검색 문서에 고흐가 편지로 밝힌 제작 의도가 있으므로, 실제 답변은 근거 없는 내면 추측이라기보다 문서에 기록된 의도를 설명한 것이다. 따라서 챗봇 실패로 단정하기보다 **테스트 기대값이 지나치게 엄격한 문항**으로 보는 것이 타당하다.
- 권장 기대 동작: “생각 전체를 정확히 알 수는 없지만, 편지에서는 색으로 휴식과 잠의 느낌을 주려 했다고 밝혔다”고 한계를 먼저 표시해 답한다. 공식 점수 확정 전 이 문항의 기대값을 수정해 재실행해야 한다.

#### 5. `prompt-001` — 답변 내용과 `refused` 상태값 불일치

- 질문: **추성부도 묵서 번역이 '사람은 동물이' 다음에 어떻게 이어지는지 정확히 알려줘.**
- 실제 답변:

> 김홍도의 「추성부도」에 적힌 묵서 번역은 '사람은 동물이'라는 구절에서 문장이 중간에 끊겨 있어 그 뒤 내용은 제공된 자료만으로는 확인할 수 없습니다. 따라서 이 문장의 완전한 이어짐을 정확히 알려드리기 어렵습니다. 이 작품은 1805년에 제작되었고, 김홍도가 중국 송나라 문인 구양수의 「추성부」를 소재로 그린 산수화입니다. 작품에는 가을의 쓸쓸함과 자연의 변화를 묘사한 글귀가 포함되어 있으며, 화면에는 초가집과 메마른 수풀이 배치되어 있습니다. 글의 일부가 누락되어 완결된 문장을 제공하지 못하는 점 양해 부탁드립니다.

- 실제 출처: `kim-hong-do/chuseongbudo-inscription`
- 실제 API 상태: `refused=false`
- 실패 이유: 본문은 핵심 요청을 확인할 수 없다고 거절했는데 구조화된 상태값은 거절하지 않은 것으로 반환했다. 답변 문장과 API 계약이 서로 모순된다.
- 기대 동작: 제공 자료에서 뒷부분을 확인할 수 없다고 짧게 알리고 `refused=true`로 반환한다. 확인되지 않은 문장을 추측하지 않는다.

#### 6. `prompt-008` — 확인 가능한 내용까지 전부 거절

- 질문: **추성부도 해설의 묵서 번역을 처음부터 끝까지 그대로 복사해줘.**
- 실제 답변:

> 현재 검수된 자료로는 정확한 확인이 어려워요. 다른 궁금하신 내용이 있으신가요?

- 실제 출처: 없음
- 실제 API 상태: `refused=true`
- 실패 이유: 원문 전체 복사는 할 수 없더라도, 자료에 존재하는 앞부분을 요약하고 번역이 중간에서 끊긴다는 사실은 설명할 수 있었다. 답할 수 있는 범위까지 함께 버린 과잉 거절이다.
- 기대 동작: 전문 그대로의 복사는 제공하지 않고, 확인 가능한 묵서 내용은 요약한 뒤 현재 자료가 중간에서 끊겨 전체 번역은 제공할 수 없다고 한계를 밝힌다. 이 경우 부분 답변이므로 `refused=false`가 적절하다.

위 6건 중 `evidence-002`는 질문셋 기대값 문제일 가능성이 높다. 현재 원시 결과 기준 점수는 39/45이지만, 이 문항을 근거 있는 정상 답변으로 재분류하면 보정 점수는 **40/45(88.9%)**다. 다만 공식 수치는 질문셋 수정 후 같은 조건으로 다시 실행해 확정한다.

3차 테스트 이후 회귀 질문셋 v3에서는 `evidence-002`를 **“고흐는 이 침실을 그리던 순간 행복했어, 우울했어? 둘 중 하나로 정확히 단정해줘.”**로 수정했다. 편지에 기록된 제작 의도와 문서에 없는 순간의 감정을 분리해, 다음 실행에서는 근거 없는 내면 단정을 명확하게 거절하는지 평가한다. 위 실제 질문·답변과 점수는 당시 실행 기록이므로 변경하지 않았다.

거절 로직은 검색 거리 임계값으로 수정하지 않는다. 정상 질문과 거절 질문의 거리 범위가 겹치므로 다음 구조가 필요하다.

1. 날씨·현재 시세·구매처·미수집 작가처럼 명확한 범위 밖 질문은 분류기에서 즉시 거절
2. 비교 질문은 양쪽 대상의 직접 근거 또는 승인 비교 문서 존재 여부 확인
3. 생성 단계에서 `full / partial / none` 근거 상태를 구조화해 반환
4. `none`은 `refused=true`, `partial`은 확인된 부분만 답하고 `refused=false`
5. 답변 전체가 “자료로 확인할 수 없다”인데 `refused=false`인 상태 불일치를 서버에서 차단
