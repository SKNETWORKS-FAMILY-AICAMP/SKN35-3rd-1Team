## 마이페이지 운영 검증

최신 마이페이지 API 경로는 운영 OpenAPI에 정상적으로 존재한다. 그러나 테스트용 Firebase 이메일 계정 2개의 올바른 ID 토큰을 운영 백엔드가 모두 `401`로 거부했다.

진단한 토큰 상태:

- 발급 프로젝트: `skn35-3rd-1team`
- issuer: `https://securetoken.google.com/skn35-3rd-1team`
- audience: `skn35-3rd-1team`
- 만료되지 않은 정상 토큰
- 운영 백엔드 결과: `401 로그인이 필요합니다.`

따라서 다음 검사는 인증 단계에서 중단되어 평가에서 제외했다.

| 항목 | 2회차 결과 | 이유 |
| --- | --- | --- |
| 인증 없는 접근 401 | 통과 | 토큰 없을 때 정상 차단 |
| 설정 서버 저장·재조회 | 평가 불가 | 정상 토큰도 401 |

가능성이 높은 원인은 Railway의 Firebase Admin 서비스 계정 또는 프로젝트 환경 설정이다. 로그를 확인할 때 토큰 값은 남기지 말고 Firebase Admin 초기화·검증 오류 종류만 확인해야 한다.
