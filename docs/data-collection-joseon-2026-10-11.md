## 수집 범위

- 김홍도: 《단원 풍속도첩》의 개별 그림 23점, 《규장각도》, 《선인야적도》. 필수 대표작인 《씨름》과 《서당》을 포함한다.

- 작품명이 같아도 소장품 번호와 원문 페이지가 다른 《정양사》 두 점은 별도 작품이다. `jeongyangsa-deoksu-1191`, `jeongyangsa-deoksu-2292`로 구별한다.

## 원문과 출처

`sources.json`은 md 파일 이름을 키로 삼는다. 필수 메타데이터 외에 `content_sha256`, `character_count`, 추출 방법, 필요한 검토 메모를 기록했다.

- 국립중앙박물관: 소장품 검색 페이지의 해설 본문 `p`를 표시 순서대로 추출했다. HTML 태그와 엔티티를 텍스트로 표현하고 문단을 나눈 것 외에 문구·오탈자·한자를 고치거나 요약하지 않았다. 작품 카드에는 같은 페이지의 작가·재질·크기·소장품 번호를 사용했다. 원래 표시값은 `source_metadata`에도 보존했다.
- 위키백과: MediaWiki API TextExtracts의 `extract`를 그대로 저장했다. API가 제공하는 본문과 `== 섹션 ==`을 보존했다. 템플릿·정보상자·각주 출력은 API가 제공하는 범위를 따른다. 판 번호·판 시각·고정판 URL·기여자 이력 URL도 기록했다.
- 각 파일에 메타데이터나 별도 제목을 덧붙이지 않았다. 번역본과 팀이 새로 쓴 연표는 만들지 않았다.

작품별 URL과 이용 조건의 전체 목록은 각 작가의 `sources.json`에 있다. 주요 확인 페이지:

- [씨름](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?schM=view&searchId=search&relicId=551), [서당](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?schM=view&searchId=search&relicId=552)
- [신묘년 풍악도첩](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?schM=view&searchId=search&relicId=49165)
- [현재 인왕제색도 소장품 정보](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?schM=view&searchId=search&relicId=36549667), [인왕제색도 제작 동기의 여러 해석](https://www.museum.go.kr/MUSEUM/contents/M0501000000.do?relicRecommendId=962060&schM=view)

## 이미지와 불확실한 값

이미지는 내려받지 않고 주소만 수집했다. 국립중앙박물관의 해당 소장품 페이지 49개에서 공공누리 제1유형 표시를 확인했다. 이 중 정양사(덕수2292-6)는 원본·미리보기 주소 모두 이미지 대신 HTML 안내 페이지를 반환하여 `image_url: null`로 두었다. 실제 사용할 수 있는 주소는 국립중앙박물관 48개와 금강전도 1개, 총 49개다. 금강전도는 [Commons 파일 페이지](https://commons.wikimedia.org/wiki/File:Geumgangjeondo.jpg)의 `Public domain` 표시를 API에서 확인했다. 본문 라이선스와 이미지 라이선스는 별도 필드에 기록했다.

- 제작 연도를 확인하지 못한 작품의 `year_label`, `year_start`는 `null`이다. 《신묘년 풍악도첩》 개별 그림은 전체 화첩과 《금강내산총도》 페이지에서 확인한 1711년을 사용했다.
- 《내연산 삼용추》는 본문의 “1734년 이후”를 `year_label`로 두고 단일 연도를 확정하지 않아 `year_start`는 `null`로 두었다.
- 재질은 기관의 표시값(`지`, `사직 - 견` 등)을 유지했다. 확인되지 않은 채색 기법을 덧붙이지 않았다. 공식 영문 제목을 확인하지 못한 작품의 `title_en`은 `null`이다.
- 원문에 서로 다른 치수가 여러 개 나오는 《선인야적도》, 《서정보월도》와 기관 자료의 치수 표기가 서로 다른 《인왕제색도》는 `dimensions: null`이다. 원래 치수는 `source_metadata`에 있다.
- 초상 이미지와 작가별 미확인 작품 Wikidata 값은 채우지 않았다.

## 검토가 필요한 5건

원문 보존과 사실 검토는 구별했다. 아래 원문을 고치지 않고 `needs_review: true`와 사유를 기록했다. 최종 검토 승인을 대신하지 않는다.

1. 김홍도 `bio.md`, `bio.en.md`: 사망 연도가 자료별로 1806년경, 1806년 이후, 1816년 이후 등으로 다르다. 작가 정보의 `death_year`는 `null`이다.
2. 정선 `bio.md`, `bio.en.md`: 한국어판의 도화서 화원 경력, 후계자가 없었다는 서술 등을 기관 자료와 대조해야 한다. 영어판도 보강했으며 번역은 A 담당이다.
3. 정선 `inwangjesaekdo.md`: 한국어 원문은 소장처를 리움미술관으로 쓰고 이병연 병문안설을 단정한다. 국립중앙박물관 자료에서는 2021년 기증과 현재 소장처, 제작 동기의 여러 견해를 확인할 수 있다. 카드 소장처는 `국립중앙박물관`으로 기록했으나 본문은 원문 규칙에 따라 수정하지 않았다. 검토 후 검색에 사용할 원문을 결정해야 한다.

나머지 문서의 `needs_review: false`는 수집 안내서의 “원문 그대로 복사” 기준을 따른다. 새 원문 전체에 대한 사람의 검수 완료를 뜻하지 않는다.

## 검증과 A 담당 후속 작업

- md 파일과 `sources.json` 키 56건이 모두 일치한다.
- 모든 문서의 필수 필드, 출처, UTF-8, JSON, 본문 SHA-256, 문서 종류별 연결 규칙을 검사했다.
- 작품 slug 50개가 유효하고 기존 작가의 작품 slug와 겹치지 않는다. 필수 대표작 4점이 모두 있다.
- 이미지 후보 주소 50개를 파일 다운로드 없이 HTTP HEAD로 확인했다. 유효한 49개는 상태 200 및 이미지 Content-Type으로 응답했다. 나머지 정양사(덕수2292-6)는 HTML 응답으로 확인되어 이미지 주소를 비웠다. 금강전도는 Commons API의 직접 주소에서 추적용 쿼리를 제거해 검증했다. 외부 주소는 이후 변경될 수 있다.
- 기존 `scripts.preprocess.build()`와 `validate()`를 사용해 로더 호환성을 확인했다. `publish()`를 실행하지 않아 `processed`를 덮어쓰지 않았다.
- 현재 매핑에는 `joseon-late-painting`이 없어 원래 상태에서는 작가 2명과 작품 50점의 사조 참조 오류 52건이 발생한다. 안내서에 따라 A가 추가할 사조를 **메모리에서만** 공급한 검증에서는 오류가 0건이다. 사조를 등록하기 전에는 전체 전처리가 성공하지 않는다.
- 원문이 짧아 전처리 후 200자 미만인 해설은 김홍도 18건, 정선 5건이다. 공식 한국어 원문의 실제 분량이며 분량을 맞추려고 재서술하지 않았다. 영어판을 추가 확보하거나 보강할 대상으로 남긴다.
- 원문 줄 끝 공백 5행은 원본을 고치지 않는 규칙에 따라 보존했다. 일반 `git diff --check`의 해당 경고는 예상되며, 줄 끝 공백 검사를 제외한 변경 검사에는 다른 문제가 없다.

A 담당 후속 작업은 `catalog.json`의 `movements`에 `joseon-late-painting`(조선 후기 회화)을 등록하고, 위 5건을 검토하며, 필요한 영어 원문을 번역한 뒤 전처리를 실행하는 것이다. 실제 TiDB 적재·청킹·임베딩은 이번 수집 범위에 포함하지 않았다.
