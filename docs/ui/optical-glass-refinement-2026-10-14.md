# 전체 페이지 글라스 디자인 개선

2026-10-14 · 프론트엔드 디자인 변경 · 로컬 dev

## 방향과 범위

작품이 가장 선명하게 보이도록 배경을 밝은 회색·옅은 민트·라일락으로 정리하고, 주 동작에는 깊은 청회색 유리를 사용했습니다. 두꺼운 테두리를 반복하기보다 하나의 유리 표면과 얇은 반사 테두리로 깊이를 표현합니다.

발견하기, 작품 목록·상세·확대 보기, 작가 목록·상세, 감상 피드, 서재 캘린더·다이어리·저장 대화, 마이페이지·컬렉션·설정, 로그인·회원가입·온보딩·확인 창에 공통 테마를 적용했습니다. 캘린더 날짜와 페이지별 필터·탭도 같은 표면과 버튼 상태를 사용합니다. API와 데이터 저장 동작을 바꾸지 않는 프론트 변경입니다.

## 공통 요소

| 요소 | 기본 상태 | 상호작용·선택 |
| --- | --- | --- |
| 주 버튼 | 진한 청회색 그라데이션, 작은 아이콘, 얇은 광택 테두리 | 누르면 내용이 살짝 눌리고 키보드 포커스는 명확한 안쪽 선 |
| 보조 버튼·아이콘 | 밝고 맑은 유리 표면 | 마우스가 올라오면 반사 테두리와 깊이가 선명해짐 |
| 가벼운 텍스트 동작 | 투명한 배경 | 마우스·누름·포커스에 유리 표면이 드러남 |
| 선택 탭·필터 | 선택 항목은 진한 유리, 나머지는 밝은 표면 | 선택 상태는 색·문자 굵기·체크 표시로 구분 |
| 카드·큰 패널 | 흰빛과 민트·라일락이 섞인 얇은 가장자리, 부드러운 그림자 | 데스크톱 포인터에 따라 가장자리 반사광이 이동 |
| 입력·목록·팝업 | 둥근 입력 테두리, 같은 색 계열과 여백 | 포커스·선택·오류를 각각 구분 |
| 대화·로그인·확인 창 | 공통 유리 패널과 버튼 | Flutter의 기존 크기 계산·키보드 회피·초점 처리를 유지 |

색 토큰은 paper `#F1F2F4`, ink `#202C34`, accent `#365B67`, muted `#606D77`입니다. 효과용 민트 `#B3E4D9`와 라일락 `#D2C9EE`는 얇은 가장자리에 사용하며 본문 글자색으로 사용하지 않습니다. 한국어 본문과 작품 제목의 기존 서체는 유지합니다.

## 컴포넌트와 적용

- `frontend/lib/ui/glass.dart`: 색, 표면, 반사 테두리, 버튼의 기본·hover·pressed·focused·disabled 상태, 필터·출처 칩, 유리 다이얼로그.
- `frontend/lib/ui/app_theme.dart`: Filled/Outlined/Text/Icon/Elevated 버튼, 입력, 세그먼트, 메뉴, 날짜 선택, 스위치, 목록, 툴팁, 알림의 공통 테마.
- `frontend/lib/ui/design.dart`: 공통 주 버튼과 작품 카드.
- 페이지별로 따로 정의했던 탭·날짜·대화 영역·작품 프레임은 위 컴포넌트와 토큰을 사용합니다.

기본 클릭·Enter 키 활성화, 비활성 버튼, 초점 표시와 기존 tooltip·semantics를 유지합니다. 큰 글자·좁은 화면에서 주 버튼의 문구는 최대 두 줄이며 넘치는 내용은 잘라 레이아웃을 보호합니다. 중요 확인 동작은 전체 문맥의 제목·본문에서도 설명합니다.

## 효과와 성능

반사광은 단순한 벡터 그림입니다. 포인터가 움직일 때 해당 표면의 페인트만 갱신하고 앱 전체 상태를 변경하지 않습니다. 6픽셀 이하의 미세한 움직임은 갱신하지 않습니다. 카드마다 배경 블러나 외부 셰이더를 쌓지 않습니다.

실제 BackdropFilter는 고정 상단 메뉴 한 곳에서만 사용합니다. 자동 재생·반짝임·무한 반복 애니메이션은 추가하지 않았습니다. reduced motion에서는 누름 전환·포인터 효과·블러를 끄고, high contrast에서는 불투명 배경과 단색 테두리로 바꿉니다. 작품 이미지와 요청 캐시·페이지 단위 불러오기는 기존 동작을 유지합니다.

자동 검증의 ‘idle frame 없음’은 조작이 끝난 뒤 반복해서 프레임을 예약하지 않는다는 뜻이며, 실제 모든 기기의 FPS 측정 결과는 아닙니다.
