# 아트로그 UI 목업 · 디자인 노트

## 시각 방향

‘일상에 한 점, 나만의 미술관’을 가칭 브랜드로 삼았습니다. 오프화이트 배경, 짙은 올리브 그린, 한국어 명조 제목과 간결한 고딕 본문을 사용합니다. 명화 이미지가 가장 큰 면적을 차지하고, 장식은 작은 아치 심벌과 가는 구분선으로 제한합니다. 드래그·복잡한 애니메이션 없이 탭, 필터, 열 배치, 채팅, 달력으로 흐름을 구성합니다.

- 배경: `#f7f6f2`
- 본문: `#252d27`
- 주요 동작: `#364e40`
- 제목: Noto Serif KR
- 본문: Noto Sans KR / DM Sans
- 영문 보조 서체: Cormorant Garamond
- 작품 이미지: 다운로드한 퍼블릭 도메인 명화 12점. 외부 이미지 서버에 의존하지 않습니다.
- 개발용 웹 화면은 Google Fonts를 사용합니다. 공유용 단일 HTML에는 현재 UI에 필요한 웹폰트 글리프를 포함했으며, 새로 입력한 문자의 일부가 서브셋에 없으면 시스템 서체로 대체됩니다.

## Streamlit으로 옮길 때

현재 저장소의 프론트엔드 구성에 맞춰 React로 제작했습니다. 정보 구조는 아래처럼 Streamlit의 기본 요소로 대응할 수 있습니다.

| 목업 요소 | Streamlit 대응 |
| --- | --- |
| 상단 메뉴 | `st.navigation` 또는 `st.page_link` |
| 사조·작가 탭 | `st.tabs` |
| 칩 필터 | `st.pills` 또는 `st.segmented_control` |
| 작품 목록 | `st.columns` + `st.image` + `st.button` |
| 작품 상세와 도슨트 | 데스크톱 `st.columns([1.12, 0.88])`, 좁은 화면에서는 순차 배치 |
| 도슨트 말풍선 | `st.chat_message` |
| 질문 입력과 추천 질문 | `st.chat_input` + `st.button` |
| 출처 | `st.expander` + 원문 링크 |
| 월별 캘린더 | `st.columns(7)` 반복, 날짜 버튼과 이미지 |
| 날짜별 한 줄 | `st.text_area` + 저장 버튼 |

실제 서비스 연결 시 좋아요·팔로우·열람 기록은 사용자별 서버 DB 저장으로 교체해야 합니다. 예시 답변은 작품 ID와 대화 맥락을 전달하는 RAG API 응답으로, 출처는 실제 검색 문서의 제목·URL로 교체합니다. 감상 제안과 문서에서 확인한 사실은 구분해 표시합니다.

## 실행과 구현 범위

`frontend/`에서 `npm install`, `npm run dev`로 실행합니다. `npm run build`는 TypeScript 검사와 정적 배포 파일 생성을 수행합니다.

백엔드·로그인·실제 LLM·벡터 검색은 연결하지 않은 UI 목업입니다. 브라우저의 실제 기록은 처음에는 비어 있으며, 작품 상세 진입 시 오늘의 기록이 추가됩니다. 서재의 ‘예시 기록 보기’는 별도 샘플 데이터를 표시하고 실제 기록을 덮어쓰지 않습니다. 도슨트에는 체험용·예시 답변임을 명시했습니다.

## 팀 공유 파일과 검증

- `output/ui/artlog-mockup.html`: 약 15MB의 단일 HTML. 앱 코드·스타일·명화 12점·웹폰트 16개 스타일·폰트 이용 조건을 포함합니다. 이 파일 하나만 전달하면 됩니다.
- 소스 앱의 데스크톱·모바일 화면과 주요 사용자 흐름을 로컬 웹 미리보기로 확인했습니다. 필터, 작가 검색, 빈 검색 결과, 제작 연도 정렬, 더 보기, 작가 상세, 좋아요, 팔로우, 새로고침 후 기록 유지, 이미지 확대·Escape 닫기, 예시 답변·출처·범위 밖 안내를 확인했습니다.
- 내보낸 HTML의 JavaScript·CSS 문법, 이미지 12점의 유효성, 폰트 포함, 외부 실행 파일 의존성 0개를 검사했습니다.
- 앱의 브라우저 보안 정책이 `file://` 열기를 막아, 내보낸 HTML의 파일 직접 실행 화면은 도구에서 검증하지 못했습니다. 위 동작 검증은 동일한 앱 소스의 로컬 웹 미리보기 기준입니다.
- 화면 캡처는 `docs/ui/previews/`에 있습니다. 개발용 웹 미리보기에서 찍은 화면이며, 감상 기록 일부는 검증 과정에서 생성한 기록입니다.
