# 리퀴드 글라스 스타일 개편

## 첫 화면과 오늘의 그림

- 오르세 미술관 홈(https://www.musee-orsay.fr/en)의 큰 작품 이미지 위에 제목과 행동 버튼을 올리는 구성을 참고했습니다. 서비스의 기존 작품 이미지를 사용합니다.
- 홈 히어로를 가로 전체·현재 화면 높이로 표시합니다. 아주 낮은 창에서는 가독성을 위해 최소 540px를 유지합니다.
- 오늘의 그림은 최대 3점이며, 이미지가 있는 큐레이터 추천 작품을 우선하고 가능한 한 서로 다른 작가를 고릅니다. 서울 날짜 기준으로 그날의 선택이 유지됩니다. 자료가 3점 미만이면 있는 작품만 표시합니다.
- 자동 재생 없이 화살표·스와이프·데스크톱 썸네일로 전환합니다. 현재 순서(01 / 03)를 표시하고, 감상 버튼은 현재 선택한 작품 상세로 연결됩니다.
- 기존 맞춤 추천 영역은 히어로 다음, 전체 작품 목록 앞에 유지합니다.

## 날짜별 그림

- 서재의 ‘월 일의 그림’은 최근 감상 목록에서 3점만 먼저 보여 줍니다.
- 더 많은 기록은 ‘전체 N점 보기’로 높이가 제한된 별도 패널을 열어 확인합니다. 긴 목록은 ListView.builder로 필요한 항목만 만듭니다.
- 감상평에 연결할 작품과 실제 감상 기록·횟수는 보존합니다. 공개/비공개 설정·캘린더·다이어리 기능은 유지합니다.

## 공통 디자인

- 배경: 차가운 화이트·옅은 블루, 본문: 짙은 네이비, 강조: 블루.
- 버튼: 캡슐형, 유리 테두리·대각선 반사 그라데이션, 44~48px 기본 터치 영역. 주요 버튼·보조 버튼·비활성 상태를 구분합니다.
- 떠 있는 글라스 내비게이션, 둥근 작품/작가 카드, 캘린더·다이어리·피드·도슨트 패널을 공통 스타일로 정리했습니다. 입력·칩·팝업·대화상자·공개 스위치에도 테마를 적용했습니다.
- Flutter 웹에서 구현한 리퀴드 글라스 스타일이며 Apple 네이티브 Liquid Glass API를 사용한 것은 아닙니다.

## 성능과 접근성

- 실제 backdrop blur는 화면 상단 내비게이션 한 곳만 사용합니다. 콘텐츠 카드와 버튼의 반사는 정적인 그라데이션과 테두리로 표현합니다.
- 고대비 또는 움직임 줄이기 설정에서는 블러를 끄고 불투명 표면으로 전환합니다. 작품 전환·카드 움직임도 줄이기 설정을 따릅니다.
- 이미지 크기 제한·요청 재사용·입력 상태 분리는 이전 성능 개선을 유지했습니다. 지속 애니메이션이나 자동 슬라이드 타이머를 추가하지 않았습니다.

## 검증

- Flutter 전체 92개 테스트 통과. 3점 선택, 실제 화면 크기의 히어로, 모바일/데스크톱 3작품 순환, 날짜별 3점 제한·별도 목록, 고대비 동작을 포함합니다.
- 기존 로그인·감상평 공개 설정·대화 복원·필터링·캘린더의 회귀 검사도 통과했습니다.
- 실제 로컬 release 웹에서 01→02→03 전환, 390px 모바일 첫 화면, 데스크톱 서재를 확인했습니다. 운영 서버 배포나 DB 변경은 이번 디자인 작업에서 수행하지 않았습니다.
